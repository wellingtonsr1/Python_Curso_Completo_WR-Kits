🔎 1. O que é Regex?

É uma “linguagem dentro da linguagem” para padrões.

Exemplo simples:

email
CPF
telefone
senha forte
logs
validação de formulários

⚙️ 2. Funções principais do re
🔹 search() → procura padrão

🔹 findall() → lista todas ocorrências

🔹 match() → começa no início

🔹 sub() → substitui

🧠 3. Metacaracteres importantes
Símbolo	Significado
.	qualquer caractere
\d	número
\D	não número
\w	letra/número
\s	espaço
+	1 ou mais
*	0 ou mais
?	opcional
^	início
$	fim

🔥 Resumo prático
Use regex quando:

✔ validar padrões
✔ extrair dados de textos
✔ limpar informações
✔ analisar logs
✔ automatizar parsing

Não use regex quando:

❌ lógica for simples (if "@" in email)
❌ código ficar difícil de ler
❌ regras forem muito complexas sem necessidade

🧠 Regra de ouro

Regex não é para escrever código bonito — é para resolver problemas de texto difíceis.
